# sprite-animation-forge

2D 게임 캐릭터 애니메이션을 이미지 생성 모델로 만들고, 결정적 후처리로 정렬·검증·패키징하는 도구.

## Language

**생성 방식 (method)**:
액션 하나의 프레임을 만들어 내는 방법. 액션마다 plan에 하나가 정해진다: `grid`(격자 시트 한 장 생성), `breathe`(정지 1장 + 결정적 호흡 변형, idle 전용), `video`(동영상 생성 후 스프라이트로 변환, 연결된 API가 있을 때만).
_Avoid_: 모드, 생성 모드, 엔진

**걸음 위상 (gait phase)**:
걷기 한 주기 안에서 한 프레임이 놓인 시점. 프레임마다 같은 만큼 나아가면 **균등 위상**이며, "프레임이 리니어하다"는 말은 이것을 뜻한다.
_Avoid_: 리니어, 선형 프레임

**자세 가이드 (gait guide)**:
걷기를 생성할 때 모델에게 함께 보여 주는, 균등 위상의 자세를 칸마다 막대 인형으로 그린 안내 그림. 정지 1장의 크기·위치를 안내하는 레이아웃 가이드와는 다른 것이다.
_Avoid_: 포즈 시트, 스켈레톤
