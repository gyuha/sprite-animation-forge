# 걷기 균등 위상 2/2: 자세 가이드(gait guide) 참조 이미지

## 목표 / 비목표
- 목표: walk를 grid로 생성할 때 두 번째 참조 이미지로 **자세 가이드**를 기본으로 붙인다. 자세 가이드는 격자와 같은 칸 배치로, 칸마다 1/2 파트의 균등 위상 자세를 막대 인형으로 그린 결정적 이미지다. 실제 Codex로 1/2(프롬프트만)와 비교해 나아졌는지 확인한다.
- **착수 전 확인**:
  - 1/2 파트의 사람 확인 결과 프롬프트만으로 충분했다면, 이 계획은 `fg-drop` 대상이다.
  - 1/2에서 "자연스러운데 QC-14 fail"이 나왔다면 임계값 재보정을 먼저 한다(이 계획에 슬라이스를 추가하거나 별도 작업으로 뺀다).
- 비목표:
  - 참조 이미지 한도(2장) 변경
  - 다방향 플랜의 비대표 방향에서 가이드 사용. 이미 2장을 쓰고 있으므로 건너뛴다.
  - 새 plan 설정 항목(`gait_guide` 같은 on/off)
  - run 등 다른 액션
  - 정면·후면 전용 가이드 그림. 측면 그림만 만들고, left는 좌우 반전으로 처리한다.

## 기준 문서(Source of truth)
- 용어집: 자세 가이드(gait guide)·걸음 위상 — `.forge/CONTEXT.md`
- 관련 ADR: 없음. 선례는 docs/04 §레이아웃 가이드(`layout_guide.py`, `layout_guide_skipped`)이다.
- 그림 제약(합의):
  - 키 색 배경에 회색 막대 인형을 그린다. 칸 배치와 크기 비율은 plan의 격자(2×3)와 같게 한다.
  - 몸 높이는 레이아웃 가이드의 머리 선·발 선 비율을 따른다.
  - 캐릭터의 **왼쪽 팔다리는 짙은 회색, 오른쪽은 옅은 회색**으로 그린다(1/2 문구의 left/right와 같게).
  - 글자·번호·격자선은 넣지 않는다.
  - 자세는 1/2의 6프레임 정의(0°, 60°, 120°, 그리고 좌우를 바꾼 3장)를 따른다.
  - 프롬프트에 `GAIT GUIDE` 블록을 추가한다: "두 번째 이미지는 칸별 자세 안내다. 자세만 따르고 선·막대 인형·색은 결과에 그리지 말 것."
  - 슬롯이 이미 2장이면 가이드를 붙이지 않고 `gait_guide_skipped` 경고를 낸다. 이때 프롬프트는 1/2 결과와 바이트 단위로 같아야 한다.
  - 프롬프트 버전 규칙은 레이아웃 가이드 선례를 따른다.
