## 계약과 다르게 한 것 (사유)
- **축소판**: sprite-gen의 원본 복원은 "영수증·산출물 5종(strip/meta/report/gif/webp)·비교 스키마·화소 단위 키 색 1단계 상한"과 결합돼 있어 재현하지 않았다. 여기서는 "만든 프레임 ↔ 원본" 선택에 한정했고 화소 단위 키 상한은 없다(미채택 표에 기록).
- 계획은 "처리된 셀"의 커버리지 비교였으나, 우리 파이프라인에서 면적이 달라지는 실제 지점은 보간 프레임(원본 대비)이므로 그 프레임으로 한정했다. 일반 셀의 처리 손상(임계값이 얇은 부위를 지우는 등)은 다루지 않는다 — 한계.
- 복원 수락 조건 3("점프 지표 악화 시 거부")은 jolt 지표 대신 점프 점수(`odd_scores`)로 판정(같은 루프 판정기 재사용).

## 학습 / 주의
- 실제로 복원이 켜지려면 "보간 프레임이 면적을 8% 넘게 잃었는데 원본 점프가 심하지 않은" 경우뿐이다 — 드문 조합일 수 있다 [낮음]. 실제 RIFE 결과로 `restore_regressed` 비율을 보고 임계를 조정할 것.
- `source-frames/`는 시트 프레임 수(≤16)만큼의 RGBA PNG(키 배경 그대로 + 알파)이며 attempt 디렉터리 크기를 늘린다.
