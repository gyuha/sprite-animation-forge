## 계약과 다르게 한 것 (사유)
- 계획의 "한 프레임 창" 재탐색을 **2프레임 창**으로: 창 1은 "같은 자리를 반대 방향으로 지나는" 반주기(포즈가 같은 두 시점)를 구분 못 해 반주기를 주기로 고른다(측정으로 확인: 걷기 주기 46에서 23이 seam 0).
- "느린 걷기"의 재탐색 조건을 "주기를 못 찾으면"에서 "이음새 비율 > 0.6 또는 동작 범위 미달"로 구체화. 첫 구현(비율 ≤ 1.0)은 전환점 근처의 6프레임짜리 가짜 이음새를 받아들였다 — 합성 데이터로 발견·보정.
- `seam_pop` 분모를 중앙값이 아닌 컷 안 최대 정상 스텝으로(스윙은 속도 분포가 치우쳐 중앙값 기준이면 정상 루프도 2.05가 나옴).
- 유지 그림 클립에서 `start`/`span`은 *그림 단위*(고른 `indices`는 원본 프레임 번호). `min_len`/`max_len`은 원본 프레임 수이며 유지 배율로 나눠 적용.
