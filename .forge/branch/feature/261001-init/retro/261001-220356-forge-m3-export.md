# 2026-10-01 — M3-b Export: Python round()가 결정성 규칙(floor(x+0.5))을 어김

## Plan vs actual
- What went as planned: atlas·Phaser JSON·animations.json·GIF·export 명령, 36건 테스트.
- Divergences: GIF 프레임 지속시간을 `round(1000/fps/10)*10`으로 구현 → Python은 은행가 반올림이라 8fps가 120ms(문서 규칙대로면 130ms). docs/05 §10 "반올림은 floor(x+0.5) 하나로 통일"을 어김. 봉인 후 직접 수정(커밋 a646c02).

## Learnings
- Do differently next time: 프로젝트 전역 규칙(결정성: 반올림 규칙, PNG 저장 옵션)은 plan의 슬라이스가 아니라 다른 문서에 있어 위임 프롬프트에서 빠지기 쉽다. 위임 프롬프트에 "docs/05 §10 결정성 규칙 준수"를 명시하고, 새 모듈이 수치를 반올림하면 `round(`를 grep해 `round_half_up`/`floor(x+0.5)`와 대조한다. eval 후보(미승격): `sprite_forge` 안에서 내장 `round(`를 쓰는 곳을 찾는 가벼운 정적 테스트 — 재발 개연성은 있으나 오탐(정수화가 목적인 곳) 정리가 필요해 사람 판단 대기.
